# The Rules of the Repo

| Skill | When it applies | Rule type | Configuration |
|---|---|---|---|
| [repo_folders_constraints](../skills/repo_folders_constraints/SKILL.md) | create, move, rename, or delete a folder or a package; add a file in a folder; add an import between packages or a dependency | Living rule with human approval | [config.md](config/repo_folders_constraints/config.md) |
| [docs_folder_system](../skills/docs_folder_system/SKILL.md) | add, change, rename, move, or delete a file or a folder in `docs` | Static rule | [config.md](config/docs_folder_system/config.md) |
| [context_md_system](../skills/context_md_system/SKILL.md) | add or edit a file in a source folder; create a source folder; change the exports or the responsibility of a folder | Living rule without human approval | none |
| [jerome-typescript-javascript-style](../skills/jerome-typescript-javascript-style/SKILL.md) | create or edit a `.ts`, `.tsx`, `.js`, `.jsx`, `.mjs`, or `.cjs` file | Static rule | none |
| [symbio_spec](../skills/symbio_spec/SKILL.md) | change the behavior of the product | Living rule with human approval | none |
